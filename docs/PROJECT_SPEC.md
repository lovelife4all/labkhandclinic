# PROJECT SPEC — کلینیک دندانپزشکی لبخند

## اهداف
افزایش جذب بیمار، رزرو آنلاین نوبت، کاهش تماس غیرضروری، مدیریت متمرکز نوبت‌ها،
پرونده دیجیتال امن، مدیریت خدمات/تعرفه/تخفیف، یادآوری پیامکی، داشبورد مدیریتی و سئوی محلی.

## معیارهای پذیرش (خلاصه)
- رزرو هم‌زمان یک بازه برای دو بیمار ممکن نباشد (تست واحد + قید Exclusion در DB).
- زمان‌های تعطیل/خارج از ساعات کاری قابل رزرو نباشند.
- تخفیف منقضی/مصرف‌شده پذیرفته نشود.
- بیمار به پرونده بیمار دیگر دسترسی نداشته باشد (RLS در فاز ۲).
- منشی به یادداشت محرمانه پزشک دسترسی نداشته باشد.
- تصویر بیمار بدون رضایت منتشر نشود.
- هیچ Secret واقعی در ریپو نباشد.

## تصمیمات فنی ثبت‌شده
- فونت Vazirmatn از پکیج npm (`@fontsource/vazirmatn`) — کاملاً Local، بدون CDN.
- منطق رزرو/تخفیف به‌صورت Pure Function در `lib/` تا هم در Demo و هم در
  Server Actions فاز ۲ قابل استفاده مجدد باشد.
- مبالغ به تومان و از نوع integer/bigint (هرگز float).
- Service Worker هرگز صفحات خصوصی/API را Cache نمی‌کند.
