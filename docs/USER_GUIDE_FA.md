# راهنمای استفاده بیمار (نسخه آزمایشی)

1. از منوی «رزرو نوبت» خدمت موردنظر را انتخاب کنید.
2. تاریخ و ساعت آزاد را انتخاب کنید.
3. نام و شماره موبایل را وارد کنید؛ در صورت داشتن کد تخفیف آن را بنویسید.
4. اطلاعات را بررسی و ثبت کنید — کد پیگیری نمایش داده می‌شود.
5. برای ورود به پنل، از صفحه «ورود» با شماره موبایل وارد شوید (در نسخه آزمایشی
   هر کد ۴ رقمی پذیرفته می‌شود).
6. در پنل بیمار می‌توانید نوبت بعدی، تاریخچه، تخفیف‌ها و امتیاز باشگاه را ببینید
   و درخواست لغو یا جابه‌جایی ثبت کنید.
