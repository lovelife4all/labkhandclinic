# کلینیک دندانپزشکی لبخند — Labkhand Dental Clinic

وب‌سایت و وب‌اپلیکیشن کلینیک دندانپزشکی لبخند (دکتر محمد درخواه — کازرون).
Next.js 15 + TypeScript + Tailwind CSS، راست‌چین و فارسی، با فونت وزیرمتن محلی.

> ⚠️ **وضعیت فعلی: Phase 0 + Phase 1 (نسخه آزمایشی تعاملی / Demo).**
> همه داده‌ها ساختگی و دارای برچسب Demo هستند. هیچ داده واقعی بیمار در این نسخه
> استفاده نشده و هیچ پیامک واقعی ارسال نمی‌شود. اتصال به پایگاه داده و احراز
> هویت واقعی در Phase 2 انجام می‌شود (اسکیما آماده است: `supabase/migrations/`).

## اجرای سریع

```bash
npm install
npm run dev        # http://localhost:3000
npm test           # تست‌های واحد منطق رزرو/تخفیف
npm run build      # بیلد production
```

## مسیرهای Demo

| مسیر | توضیح |
|---|---|
| `/` | صفحه اصلی |
| `/services`, `/pricing` | خدمات و تعرفه‌ها |
| `/booking` | رزرو آزمایشی نوبت (چندمرحله‌ای) |
| `/login` | ورود آزمایشی (OTP نمایشی) + ورود آزمایشی پزشک/منشی |
| `/patient` | پنل بیمار آزمایشی |
| `/secretary` | پنل منشی آزمایشی |
| `/admin` | پنل پزشک آزمایشی (داشبورد، نوبت‌ها، خدمات، تخفیف، مقالات، گالری، نمودار دندان، گزارش CSV) |
